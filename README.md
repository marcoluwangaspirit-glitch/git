# Git

## Purpose
this project demonstrates hot Git and GitHub help developers  collaborate and manage sofware releases.

## Tools
- Git
- GitHub
- GitHub Issues
- GitHub Actions

## objectives
- Track changes to source code.
- Use feature branches and pull requests.
- Review and test changes before merging.
- Tag releases for traceability.

## Development Workflow
1. Create a feature branch for each new feature.
2. commit changes with clear messages.
3. Push the feature branch to GitHub.
4. Open a pull request for review.
5. Run tests before merging into main.
6. Tag completed releases for traceability.
